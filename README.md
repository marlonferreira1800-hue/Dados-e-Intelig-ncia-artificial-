# Dados, Inteligência Artificial e Dashboards

Repositório para aprender, desenvolver e documentar projetos nas áreas de **análise de dados**, **inteligência artificial** e **dashboards**.

## Áreas de trabalho

- **Dados:** coleta, limpeza, análise e visualização de dados.
- **Inteligência artificial:** estudos, experimentos e aplicações práticas de IA.
- **Dashboards:** painéis interativos para acompanhar indicadores e comunicar resultados.

## Como organizar cada projeto

Cada projeto deve ter, sempre que possível:

1. Uma descrição do problema e do objetivo.
2. A origem dos dados e as instruções de uso.
3. Os arquivos de código e dependências necessárias.
4. Imagens ou capturas de tela dos resultados.
5. Um resumo das conclusões e limitações.

## Cuidados com dados

Não publique senhas, chaves de API, dados pessoais ou arquivos confidenciais. Use dados públicos, anonimizados ou sintéticos e informe a fonte dos dados.
